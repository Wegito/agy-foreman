# Known Issues & Workarounds

This table documents live-verified quirks, bugs, and edge cases encountered when running the official Antigravity CLI (`agy`) in headless mode, along with the source of each finding and how `agy-foreman` mitigates it.

## Live-Verified Issues with Sources

| Issue                                                                                                                                                                                                | Source                                                                                                           | Handling                                                                                                               |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| When quota runs out, agy retries silently until `--print-timeout`, then exits 0 with empty output                                                                                                    | agy-bridge, claude-agy-mcp                                                                                       | 429 detection in log or stream, then kill → `quota`                                                                    |
| Headless mode soft-denies permissioned tools and still exits 0                                                                                                                                       | [headless docs](https://antigravity.google/docs/cli/headless/)                                                   | Deny notices or empty response = failure; pre-grant permissions                                                        |
| `--mode plan` is advisory and can still write                                                                                                                                                        | claude-agy-mcp (agy 1.2.1/1.2.2)                                                                                 | Explore runs in a throwaway detached worktree with read-only hooks                                                     |
| An open stdin pipe hangs agy                                                                                                                                                                         | agy-bridge source                                                                                                | Always close stdin when spawning agy                                                                                   |
| Default `--print-timeout` is 5 min                                                                                                                                                                   | headless docs                                                                                                    | Always passed explicitly                                                                                               |
| Prompt argument size limits (Linux 128 KiB; ~24k chars seen on Windows)                                                                                                                              | claude-agy-mcp, CLI-Subagents                                                                                    | The brief goes in a file (`.agy-task/brief.md`) and the prompt command just points at it                               |
| Cold start takes several seconds to ~45 s                                                                                                                                                            | agy-bridge, claude-agy-mcp                                                                                       | Token and routing rules filter out tiny tasks                                                                          |
| The self-report can claim green tests                                                                                                                                                                | all bridges                                                                                                      | Server verification runs tests independently; Gemini's report is fenced as untrusted                                   |
| Knowledge cutoff predates new APIs                                                                                                                                                                   | [Google prompting guide](https://ai.google.dev/gemini-api/docs/prompting-strategies)                             | Include current date plus pinned dependency versions in the brief                                                      |
| Windows uses the older permission system, and the sandbox is Preview                                                                                                                                 | [permissions](https://antigravity.google/docs/permissions/), [sandbox](https://antigravity.google/docs/sandbox/) | External worktree isolation plus server-side checks form the safety layer                                              |
| Windows doesn't kill the process tree from a group kill                                                                                                                                              | agy-bridge (`kill(-pid)` is POSIX only)                                                                          | Use `taskkill /T /F /PID` on Windows to cleanly terminate processes                                                    |
| **When `--print-timeout` fires, agy returns `status: SUCCESS`, an empty response and exit code 0** (stderr: `[agy] print timeout after … returning partial output`)                                  | Live run, agy 1.4.0, 2026-10-17                                                                                  | Classified as `timeout` by the server                                                                                  |
| `--print-timeout` **defaults to 0s (no limit)** in agy 1.4.0                                                                                                                                         | `agy --help`                                                                                                     | Always passed explicitly by the runner                                                                                 |
| Headless runs **inherit the user's global agy plugins, skills, MCP servers and permission mode** (`always-proceed` overrode `--mode plan`, it loaded superpowers, and it called the socraticode MCP) | Live run                                                                                                         | Workspace hook intercepts and denies unallowed tools; server checks remain the safety layer                            |
| **Hard word or length limits make Flash loop**: it wrote ~15 scripts to count words in its own draft and ran out the clock                                                                           | Live run                                                                                                         | Never set hard word or character count limits in briefs; ask for structured sections and let the server truncate       |
| agy's `--log-file` contains the user email                                                                                                                                                           | Live run                                                                                                         | Log written to private temp dir, watched for quota, deleted after run, never returned                                  |
| **Worktrees contain only committed files**: uncommitted or git-ignored files are missing for Gemini, and dependencies are absent until `setup_command` runs                                          | Found while dogfooding (2026-10-17)                                                                              | Commit everything referenced in brief; `setup_command` runs in every fresh worktree; `dry_run` inspects rendered state |
